Titanic Survival Prediction – Data Cleaning Project
📌 Project Overview
This project focuses on cleaning and preprocessing the Titanic dataset using Python.
🛠️ Technologies Used
Python
Pandas
Scikit-learn
Matplotlib
📊 Tasks Completed
Loaded the Titanic dataset using Pandas
Explored the dataset using .info() and .describe()
Checked for missing values
Filled missing values in the Age column using median imputation
Filled missing values in the Embarked column using mode
Removed the Cabin column because it contained many missing values
Encoded the Sex column using LabelEncoder
Encoded the Embarked column using OneHotEncoder
Visualized the Age distribution using Matplotlib
Saved the cleaned dataset as a CSV file
📁 Output
The cleaned dataset is saved as:
Titanic_Cleaned_Dataset.csv
